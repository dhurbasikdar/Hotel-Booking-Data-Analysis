# Hotel Booking Data Analysis

Exploratory data analysis of hotel booking demand data using Python.

## Tools
Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

## What I did
- Cleaned data (handled missing values, dropped columns, removed outliers)
- Analyzed cancellation rates by hotel type
- Compared Average Daily Rate (ADR) of City vs Resort hotels
- Visualized monthly reservation trends and market segments

## How to run
1. Clone the repo
2. Install: `pip install pandas matplotlib seaborn jupyter`
3. Open `Data_Analysis_Hotel_Booking_.ipynb` and run all cells
